
永久全局静止所有 GIF，鼠标悬浮至图上才动

- 文件 → 偏好设置 → 外观 → **打开主题文件夹**
- 在文件夹空白处新建文件，命名为 `base.user.css`
- 复制下面全部代码粘贴进去，保存文件

```css
/* 全局禁止GIF自动播放，只显示第一帧静态图 */
#write img[src$=".gif"] {
  animation-play-state: paused !important;
}
/* 鼠标悬停才播放，按需保留/删除这段 */
#write img[src$=".gif"]:hover {
  animation-play-state: running !important;
}
```

完全关闭 Typora，重新打开，所有 GIF 默认静止，鼠标放上去才动。

> 想全程永远不动、悬停也不播放，删掉第二组 `:hover` 代码即可。
