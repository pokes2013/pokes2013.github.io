# 单据通用状态 + 对应操作按钮（ERP/MES/HRM/进销存通用版，可直接用在前端页面）

> 说明：不同系统略有差异，下面是工厂业务系统最常用一套，你可以按需删减。

| 单据状态 | 状态说明 | 页面显示按钮 |
| ---- | ---- | ---- |
| **草稿** | 新建保存，未提交；可随意修改删除 | 提交、编辑、删除、打印 |
| **待审核** | 已提交，等待上级审核 | 撤销提交、查看、打印 |
| **审核通过** | 审批完成，正式生效 | 查看、打印、导出、【部分场景：作废】 |
| **审核驳回** | 审核不通过，退回制单人 | 编辑、重新提交、查看、打印 |
| **执行中** | 单据已生效，业务正在进行（生产/入库/发货） | 查看、打印、终止、进度上报 |
| **已完成** | 业务全部执行完毕，闭环 | 查看、打印、导出（不可编辑） |
| **已作废** | 单据生效后取消，数据保留，不参与核算 | 查看、打印（不可编辑、不可恢复） |
| **已关闭** | 部分系统单独区分：单据还有剩余数量，但手动关闭不再执行（采购订单常用） | 查看、打印 |
| **已取消** | 草稿/待审阶段直接取消（和作废区分：未正式生效） | 查看、打印 |

## 简要区分概念（写需求文档用）
1. **取消**：草稿/待审核阶段，未生效，取消后不进入业务流程
2. **作废**：已经审核通过生效，业务取消，保留单据记录，财务/库存不记账
3. **关闭**：多用于订单，不删除单据，剩余数量不再执行，历史记录保留

## 前端按钮规则要点
- 草稿：**允许编辑删除**
- 待审核：不能编辑，只能撤销回到草稿
- 审核通过：不能修改主数据；部分单据允许新增子单/做执行操作
- 已完成/已作废：**只允许查看打印导出，禁止编辑**
